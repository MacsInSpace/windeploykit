# App icons

This directory contains the generated Unofficial Manager application icons used
by Tauri for macOS, Windows, and development builds.

The current icon set was generated from the project owner's supplied
`Logo.pdf` artwork and resized into the PNG, ICNS, and ICO files referenced by
`tauri.conf.json` (`bundle.icon`).

If the artwork changes later, regenerate every file in this directory together
so the macOS `.icns`, Windows `.ico`, and PNG build icons stay visually aligned.
